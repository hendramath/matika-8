🔢 Eksponen

Eksponen adalah bentuk perkalian berulang dari suatu bilangan dengan dirinya sendiri.

1. Pengertian Eksponen

Bentuk umum bilangan berpangkat adalah:

an = a × a × a × ... × a

Sebanyak n faktor.

2. Perkalian Pangkat dengan Basis Sama

am × an = am+n

Contoh:

23 × 24 = 27 = 128

3. Pembagian Pangkat dengan Basis Sama

am ÷ an = am−n

Contoh:

56 ÷ 52 = 54 = 625

4. Pangkat dari Pangkat

(am)n = am×n

Contoh:

(23)2 = 26 = 64

5. Pangkat Nol

a0 = 1

Untuk a ≠ 0.

6. Pangkat Negatif

a−n = 1 / an

7. Pangkat dari Perkalian

(ab)n = anbn

8. Penerapan

Eksponen dapat digunakan untuk menyatakan pertumbuhan, luas, volume, ukuran sangat besar atau sangat kecil, dan berbagai permasalahan dalam kehidupan sehari-hari.

📐 Teorema Pythagoras

Teorema Pythagoras digunakan untuk menentukan panjang sisi pada segitiga siku-siku.

1. Pengertian

Pada segitiga siku-siku, kuadrat sisi miring sama dengan jumlah kuadrat kedua sisi siku-sikunya.

a2 + b2 = c2

Keterangan:

  • a = sisi siku-siku
  • b = sisi siku-siku
  • c = sisi miring/hipotenusa
Ingat! Sisi miring adalah sisi yang berada di depan sudut siku-siku dan merupakan sisi terpanjang.

2. Menentukan Sisi Miring

Jika kedua sisi siku-siku diketahui:

c = √(a2 + b2)

Contoh:

a = 3, b = 4

c = √(32 + 42)
c = √(9 + 16)
c = √25
c = 5
Jadi sisi miringnya adalah 5.

3. Menentukan Sisi Siku-Siku

Jika sisi miring dan salah satu sisi siku-siku diketahui:

a = √(c2 − b2)

Contoh:

c = 13, b = 5

a = √(132 − 52)
a = √(169 − 25)
a = √144
a = 12
Jadi sisi yang belum diketahui adalah 12.

4. Tripel Pythagoras

Tripel Pythagoras adalah tiga bilangan positif yang memenuhi hubungan Pythagoras.

3, 4, 5
5, 12, 13
6, 8, 10
8, 15, 17
7, 24, 25

5. Kebalikan Teorema Pythagoras

Jika tiga sisi suatu segitiga memenuhi:

a2 + b2 = c2

maka segitiga tersebut merupakan segitiga siku-siku.

6. Penerapan dalam Kehidupan

Teorema Pythagoras dapat digunakan untuk menentukan:

  • panjang tangga yang bersandar pada dinding;
  • diagonal persegi panjang;
  • jarak antara dua titik;
  • panjang kabel atau tiang;
  • berbagai permasalahan geometri.
